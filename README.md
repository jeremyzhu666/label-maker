# Label Maker 标签生成工具

在浏览器里设计并打印四宫格标签。支持精臣蓝牙直连，无需安装。

## 在线使用

地址：https://jeremyzhu666.github.io/label-maker/

推荐 Chrome 或 Edge 桌面版打开。

## 功能

- 四宫格模板，实时预览
- 蓝牙直连精臣打印机，一键打印
- 支持浓度、份数、偏移调节

## 使用步骤

1. 打开在线地址
2. 在四宫格内填写标题和内容
3. 右侧预览实时显示效果
4. 连接打印机并打印

## 兼容性

| 环境 | 编辑 | 蓝牙打印 |
|---|---|---|
| Chrome / Edge 桌面版 | 支持 | 支持 |
| macOS Safari | 支持 | 不支持 |
| iOS | 支持 | 请用 Bluefy 浏览器 |

## 常见问题

- **蓝牙搜不到打印机？** 确认打印机已开机，关闭系统里之前配对过的同名蓝牙，回到浏览器重新连接。
- **内容放不下？** 系统会自动缩小字号适配。
