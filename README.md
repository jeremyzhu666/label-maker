# Label Maker 标签生成工具

浏览器里设计并打印四宫格标签。支持精臣 Niimbot 蓝牙直连，也能导出 JPG 用任意打印机打印。无需安装、无需登录，数据只存你自己的浏览器。

## 在线使用

地址：https://jeremyzhu666.github.io/label-maker/

推荐 Chrome / Edge 桌面版打开。建议收藏书签随时用。

## 功能

- 四宫格模板，800 × 600 高清画布，300dpi 打印清晰
- 四字段标题可自定义（默认 名称 / 编号 / 日期 / 自定义），自动记住上次输入
- 实时预览，所见即所得
- 导出高清 JPG，发微信、发打印店、拷 U 盘都行
- 蓝牙直连精臣 Niimbot：选型号、选标签纸、调浓度、设份数、偏移校准，一键打印

## 使用步骤

1. Chrome / Edge 桌面版打开在线地址
2. 在四宫格内填写「标题」和「内容」
   - 标题改成你需要的字段名（如 名称、编号、日期、自定义）
   - 标题自动记住，下次打开无需重填
3. 右侧预览实时显示打印效果
4. 导出或打印：
   - **没有精臣打印机 / 想发给别人打**：点「下载 JPG」保存高清图，发微信时选「原图」，或拷到 U 盘，用任意打印机打 40 × 30mm 标签纸
   - **有精臣打印机**：打开电脑蓝牙 + 打印机开机 + 装好标签纸 → 点「连接打印机」选中机型 → 选型号、标签尺寸、份数、浓度 → 点「立即打印」

## 适配机型

- 品牌：精臣（Niimbot）
- 型号：B1、B1 Pro、B2 Pro、M2-H、D11_H、D110、N1

支持 203dpi 和 300dpi 多种标签尺寸（15 × 30、20 × 40、25 × 25、30 × 30、40 × 30、50 × 30、50 × 80、60 × 40 等，横竖版式都有）。

## 常见问题

- **蓝牙搜不到打印机？**
  1. 确认打印机已开机 + 标签纸装好
  2. 关闭系统里之前配对过的同名蓝牙，回到 Chrome 重新搜
  3. 重启打印机，再点「连接打印机」
  4. 仍失败：点「下载 JPG」，用精臣官方 APP 打印
- **标签发微信后变糊？** 发送时选「原图」，源文件是高清版，无损。
- **内容字数多放不下？** 系统会自动缩小字号适配，超出部分显示省略号。
