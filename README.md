## 🏷️ 一步到位使用流程
1. **推荐用 Chrome / Edge 桌面版打开**（手机也能用，蓝牙只支持桌面 Chrome/部分 Android Chrome）
2. **标签编辑**：改 4 个字段就好（自动记住上次输入，下次不用重填）
   - **第一块 DATE**：拍摄日期，格式建议 `YYMMDD`（如 250822）
   - **第二块 ITEM / QTY**：型号（默认 *Apple A01*，机械键盘就改 *Keychron K2* 之类）/ 数量
   - **第三块 PROJECT**：项目名（如 *EV - AUDI E7X Launch PV*）
   - **第四块 MARK / NO**：场记标记 / 盒号或编号（默认 A01）
3. **标签预览**：实时看 400×300 打印效果
4. **导出 / 打印**：
   - 🖨️ **有精臣打印机（B1 Pro / B2 Pro / D110 / N1 等）**
     1. 打开电脑蓝牙 + 打印机电源 + 装好标签纸
     2. 点「连接打印机」→ 弹窗选中你的精臣机型 → 稍等连接成功
     3. 点「直接打印」→ 打完一张会回写份数，多份直接点继续
   - 📤 **没有打印机 / 手机上 / 发别人打印**
     1. 点绿色 **「下载 JPG」** → 保存 400×300 PNG
     2. 发微信群 / 发打印店 / 拷 U 盘，直接用任意打印机打 40×30mm 标签纸

## 💡 小贴士
- **日期格式**：统一 `YYMMDD`（250822 = 2025-08-22），后期归档检索最省心
- **数量框**：直接数字，不用加 `pcs / 个 / 卷`，默认提示里说了
- **蓝牙搜不到打印机？**
  1. 确认开机 + 标签纸装好（绿色灯常亮）
  2. 关闭系统里之前连过的同名蓝牙配对，回到 Chrome 里重新搜
  3. 重启打印机，再点「连接打印机」
  4. 仍失败：下载 JPG，用官方 Niimbot APP 打印（兼容性 100%）
- **标签发微信群后变糊？** 选「原图」发送，JPG 源文件是 400×300 精臣官方尺寸，无损
