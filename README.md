# 精臣 Niimbot 标签模板生成器

四宫格标签模板在线生成，可直接连接精臣打印机打印。

## 在线地址

https://jeremyzhu666.github.io/label-maker/

## 兼容性

请使用 Chrome 浏览器（电脑或手机）打开以上链接即可使用。

## 使用方法

1. 打开在线网址
2. 在「标签编辑」填写四块标签内容：
   - 第一行：模板标题（名称 / 编号 / 数量 / 备注等）
   - 第二行：要打印的具体内容
3. 在「标签预览」确认效果
4. 在「标签打印」选择：
   - 打印机型号
   - 标签纸尺寸
   - 浓度
   - 打印份数
5. 两种出图方式：
   - **直接打印**：点「连接打印机」，在系统弹窗里选择你的精臣设备，点「直接打印」
   - **下载 JPG**：保存为图片后去任意 App 打印

## 支持的精臣打印机

- B1 Pro
- B2 Pro
- B1
- D110
- D11_H
- N1
- M2-H

默认适配 14 x 50 mm 四宫格标签纸，可在页面下拉菜单切换其它规格。
